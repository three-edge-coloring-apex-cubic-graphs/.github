# External programs and files for the computer checks in "Three-edge-coloring apex cubic graph"

The following repositories contain the configurations, discharging rules, and programs used to verify the proofs in "[Three-edge-coloring apex cubic graph](https://arxiv.org/abs/2608.22870)".

+ [configurations](https://github.com/three-edge-coloring-apex-cubic-graphs/configurations): Contains 915 configuration files.

+ [discharging-rules](https://github.com/three-edge-coloring-apex-cubic-graphs/discharging-rules): Contains 70 discharging rule files, and 4 auxiliary rule files.

+ [computer-checks](https://github.com/three-edge-coloring-apex-cubic-graphs/computer-checks): Contains the programs for computing free homomorphic images, computing combined rules, enumerating cartwheels, and recursively computing homomorphic images of configurations.

+ [semi-reducibility-checker](https://github.com/three-edge-coloring-apex-cubic-graphs/semi-reducibility-checker): Contains the program for checking the semi-reducibility of multi-boundary islands.

## Reproducibility of our work

For those interested in independently reproducing our computational work, whether manually or by using LLMs, we provide instructions for writing source code.
We also outline several key metrics that should be consistent across all correct implementations.
Please consult the [instructions-for-checking-reproducibility](https://github.com/three-edge-coloring-apex-cubic-graphs/instructions-for-checking-reproducibility).
